# Manual Record & Replay Madoglio

Skill portátil para Codex e outros harnesses de IA compatíveis com o padrão Agent Skills.

## Instalação sugerida
Clone ou baixe este repositório e instale a pasta da Skill pelo mecanismo disponível no seu harness. No Codex, a pasta pode ser copiada para o diretório de Skills da conta; em outros ambientes, mantenha `SKILL.md` como ponto de entrada e trate `agents/openai.yaml` como metadado opcional.

## Uso
Prepare uma pasta de evidências com:
- gravação curta de tela;
- áudio ou transcrição;
- screenshots ordenados.

Depois invoque a Skill pedindo para aprender o procedimento e gerar uma Skill filha.

## Observação
O método é uma aproximação orientada por evidências ao Record & Replay. Ele não substitui nem replica a telemetria interna do recurso nativo.
